# LemonPlayer 需求清单

> 版本：v0.1（讨论稿） · 更新：2026-11-03 · 状态：M0 需求冻结中
> 维护约定：需求编号一旦分配不再复用；状态用 ✅ 已完成 / 🚧 进行中 / ⬜ 未开始 / ⏸️ 挂起 / ❌ 取消。

---

## 1. 项目定位

**LemonPlayer** 是一款 Swift / SwiftUI 原生 iOS/iPadOS 应用：把**光鸭云盘**当媒体源直接挂载，无需下载即可流式播放，并具备专业级**外挂字幕**能力（SRT / WebVTT / ASS 特效、自动匹配、编码识别、时间轴校准、样式定制）。

一句话：**光鸭云盘上的 Infuse / Fileball，原生 Swift 实现，字幕能力是一等公民。**

### 1.1 与竞品的差异点

| 维度 | 通用播放器（Infuse/VLC） | 光鸭官方 App | LemonPlayer |
|---|---|---|---|
| 光鸭直连（扫码登录、直链播放） | 需手动 WebDAV/配置 | 有，但播放能力弱 | ✅ 原生支持 |
| 外挂字幕（ASS 特效 / 编码识别 / 时间轴校准） | 部分支持 | 弱 | ✅ 全量支持 |
| 媒体库海报墙（TMDB） | ✅ | 无 | ✅ |
| 离线缓存 | ✅ | 有限 | ✅ |
| 构建方式 | 闭源/大工程 | 闭源 | 开源 + GitHub Actions 出包 |

### 1.2 目标用户与核心场景

1. **自建影视库玩家**：光鸭云盘存了几百部 MKV/HEVC，想在 iPhone/iPad 上直接看，带中文字幕。
2. **追剧用户**：剧集自动连播、断点续播、下一集。
3. **离线场景**：地铁/飞机上，提前缓存，字幕照常可用。
4. **字幕党**：手上有 ASS 特效字幕（字体、定位、卡拉OK），要求还原度高；SRT 常是 GBK 编码，要求不乱码；片源与字幕不同步，要求能校准。

## 2. 功能需求

优先级：**P0** = v1 必须（否则不可用）；**P1** = v1 应有（体验关键）；**P2** = 后续版本。

### 2.1 账号与登录（F-AUTH）

| 编号 | 需求 | 优先级 | 说明 / 验收标准 |
|---|---|---|---|
| F-AUTH-01 | 扫码登录（OAuth2 设备码流程） | P0 | 展示二维码 + 轮询状态；扫码成功 5s 内进入主界面；二维码过期可刷新 |
| F-AUTH-02 | 登录态持久化 | P0 | token/refresh_token 存 Keychain（非 UserDefaults）；冷启动自动恢复，无需重登 |
| F-AUTH-03 | Token 自动刷新 | P0 | access_token 过期前静默刷新；刷新失败（refresh 失效）跳登录页并保留上次路径 |
| F-AUTH-04 | 多账号切换 | P1 | 支持保存 ≥2 个账号并在设置中切换；切换后清空对应缓存 |
| F-AUTH-05 | 退出登录 | P0 | 清除 Keychain、网盘缓存、下载任务（二次确认） |
| F-AUTH-06 | 登录异常提示 | P0 | 网络失败 / 二维码过期 / 账号被限制 分别给出可操作提示 |
| F-AUTH-07 | 开发调试 token 注入 | P2 | 设置页隐藏入口：手动粘贴光鸭 access_token 用于联调（仅 DEBUG 构建 + 二次确认），文档见 `docs/api/GUANGYA_API.md` 附录 A |

### 2.4 外挂字幕（F-SUB）——核心差异功能

| 编号 | 需求 | 优先级 | 说明 / 验收标准 |
|---|---|---|---|
| F-SUB-01 | SRT 解析 | P0 | 标准 SRT；容错（缺序号、时间格式 `,`/`.`、重叠条目） |
| F-SUB-02 | WebVTT 解析 | P0 | 含 cue 样式/位置（基础） |
| F-SUB-03 | ASS/SSA 渲染 | P0 | 走 libass：字体、定位、特效、卡拉OK 完整渲染；字体缺失有兜底 |
| F-SUB-04 | 同名自动匹配 | P0 | 文件名规范化（去扩展名、去 `[]`/`()` 标签、去清晰度/编码词）；匹配 `.zh.srt`/`chs.srt`/`.ass` 等；命中多个时弹选择 |
| F-SUB-05 | 手动导入 | P0 | ① 系统文档选择器选本地文件 ② 从光鸭网盘任意目录选字幕文件；两种入口均在播放器字幕面板内 |
| F-SUB-06 | 编码识别 | P0 | 自动检测 UTF-8/BOM/GBK/GB18030/BIG5/UTF-16；失败可手动指定；GBK 中文不出现乱码 |
| F-SUB-07 | 时间轴校准 | P0 | 整体延迟 ±（0.1s 步进，实时预览）；可保存到该文件；支持重置 |
| F-SUB-08 | 样式设置 | P1 | 字号、颜色、描边/阴影、背景不透明度、底部边距；SRT/VTT 自绘生效；ASS 支持"强制覆盖"开关 |
| F-SUB-09 | 双语字幕 | P1 | 主/副两条外挂字幕同时显示（中文 + 英文），位置不重叠 |
| F-SUB-10 | 按文件记忆 | P0 | 记住每个文件选中的字幕、延迟、样式覆盖 |
| F-SUB-11 | 在线字幕搜索 | P2 | v1 不做（需第三方字幕源，合规与稳定性风险） |
| F-SUB-12 | 字幕预览屏 | P1 | 调整样式/延迟时有独立预览区（静态片帧 + 字幕叠加） |
| F-SUB-13 | 自定义字体导入 | P2 | 为 ASS 特效字幕导入 TTF/OTF 并注册到渲染层 |

## 3. 非功能需求（N）

| 编号 | 类别 | 要求 |
|---|---|---|
| N-01 | 平台 | iOS/iPadOS **26.0+**（Xcode 26 构建）；iPhone + iPad 布局适配 |
| N-02 | 语言 | 简体中文优先；文案集中在 String Catalog，预留英文 |
| N-03 | 架构 | SwiftUI + Observation（`@Observable`）+ MVVM；按 SPM 拆模块；Swift 6 严格并发 |
| N-04 | 性能 | 冷启动 < 2s（含登录态恢复）；1GB MKV 起播 < 3s；seek < 1.5s；列表滚动 60fps |
| N-05 | 稳定性 | 崩溃率目标 < 0.1%；网络异常、token 失效、格式不支持必须优雅降级而非闪退 |
| N-06 | 体积 | IPA 安装后 < 300MB（含播放内核与 FFmpeg 组件） |
| N-07 | 安全 | token 仅 Keychain；日志脱敏（不打印 token/URL 签名）；仅 HTTPS（ATS 默认） |
| N-08 | 可测试性 | 纯逻辑层（字幕解析、文件名解析、API 编码、编码检测、时间轴模型）单测覆盖率 ≥ 80%，CI 必跑 |
| N-09 | 构建 | GitHub Actions（macos-26 + Xcode 26）产出未签名 IPA + 模拟器构建产物；PR 必过 CI |
| N-10 | 可维护性 | 模块边界清晰；docs/ 为准，需求/进度与新功能同步更新；关键决策写 ADR |
| N-11 | 合规 | 开源许可清单（VLCKit 为 LGPL、MPVKit 含 LGPL/GPL 组件）需在"关于"页展示；隐私清单 PrivacyInfo.xcprivacy |
| N-12 | 无障碍 | 动态字体、VoiceOver 标签（P1）；对比度符合 WCAG AA |
| N-13 | 兼容 | 支持 iPhone 竖横屏、iPad 全方向；分屏/Slide Over 不崩溃 |

## 4. 技术约束

| 编号 | 约束 | 影响 |
|---|---|---|
| C-01 | 开发机为 Windows，无 Xcode / Swift 工具链 | 编译验证只能靠 GitHub Actions；纯逻辑需本地可跑（Swift for Windows 可选） |
| C-02 | 光鸭云盘 API 为社区逆向接口，无官方文档/承诺 | 接口可能变更、限流、风控；必须做客户端抽象与降级（WebDAV 预留） |
| C-03 | 播放内核引入二进制依赖（MPVKit/VLCKit） | 体积、GPL/LGPL 合规、App Store 审核、SPM 缓存策略 |
| C-04 | 无 Apple 开发者账号时只能侧面 IPA 安装（7 天签名） | 交付说明需覆盖自签路径 |
| C-05 | TMDB API 需 Key，国内网络可达性不稳定 | v1 先用占位数据跑通流程，Key 后补；失败时用兜底占位 |
| C-06 | 光鸭无搜索接口；直链有效期/CDN host/防盗链策略均**未验证** | 搜索走本地索引；直链按"短寿命、用完即弃 + 403 自动重取"实现；真机抓包回填 `docs/api/GUANGYA_API.md` 待验证项 |

## 5. 范围外（v1 不做）

- 在线字幕库搜索与自动下载（P2，合规风险）
- 弹幕、直播、投屏（DLNA/Chromecast）、多端同步播放进度（云端）
- macOS / tvOS / visionOS 移植
- 网盘的写操作（上传/重命名/删除/回收站）——只读浏览
- 视频转码/压制（服务端能力不允许）
- WebDAV / S3 等其它存储源接入（架构预留）

## 6. 风险与对策

| 编号 | 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|---|
| R-01 | 光鸭 API 变更或风控导致不可用 | 中 | 高 | 网络层抽象 + 运行时可诊断；紧跟社区实现；预留 WebDAV 降级路径 |
| R-02 | 无本地 Xcode，编译错误迭代慢 | 高 | 中 | 小步提交、模块先建可编译骨架、CI 每次推送即建；纯逻辑先本地/单测验证 |
| R-03 | 第三方内核 HDR/杜比视界/AV1 支持不完整 | 中 | 中 | v1 明确支持矩阵，播放失败给出"用外部播放器打开"入口 |
| R-04 | PiP/AirPlay 与自定义渲染层不兼容 | 中 | 中 | 技术预研结论写入 ADR，不支持则 v1 置灰并说明 |
| R-05 | App Store 审核（GPL、后台、私有 API） | 低-中 | 高 | 用 LGPL 构建、避免私有 API、后台能力按规范声明；自签分发作为兜底 |
| R-06 | 无开发者账号，自签 7 天过期 | 高 | 中 | 文档说明 AltStore/Sideloadly 续签流程；提供 signed 工作流模板（用户填证书） |
| R-07 | TMDB 在国内不可达 | 中 | 中 | 可配置镜像域名；失败时显示本地占位并允许手动填写海报 URL |
| R-08 | 双内核（ASS 自绘 + 内核 libass）渲染不一致 | 中 | 中 | 统一字幕渲染管线：ASS 走内核 libass，SRT/VTT 走自绘 overlay；样式面板按格式自适应 |

## 7. 验收方式

### 7.1 关键用户旅程（发布前必须全绿）

| 编号 | 旅程 | 通过标准 |
|---|---|---|
| J-01 | 扫码登录 → 浏览目录 → 播放 MKV → 加载 ASS 字幕 → 拖动 seek | 全流程无崩溃；ASS 特效正确；seek 后字幕同步 |
| J-02 | 播放 SRT（GBK）→ 自动匹配 → 修正延迟 +1.5s → 重进 | 不乱码；延迟保存并恢复 |
| J-03 | 批量下载整季 → 开飞行模式 → 离线播放 | 下载完成、离线可播、字幕可用 |
| J-04 | 推送到 main → GitHub Actions | 构建通过、产出 IPA artifact、单测通过 |

### 7.2 质量门槛（每个里程碑）

- `swift test` / `xcodebuild test` 全绿，纯逻辑覆盖率 ≥ 80%
- 无 Swift 6 并发警告（或用 `@preconcurrency` 并注释原因）
- 新增用户可见功能必须有：空态、错误态、加载态
- 文档同步：REQUIREMENTS / TASKS / PROGRESS 至少更新一处

## 8. 需求变更流程

1. 新需求先写进本文件（分配新编号），标注来源（用户反馈/技术债/风险）。
2. 影响里程碑的变更同步更新 `docs/GOALS.md` 并在 `docs/PROGRESS.md` 记录变更原因。
3. 架构级决策（内核、存储、分发）必须新增 ADR（`docs/DECISIONS.md`）。
4. 需求取消不删除，标记 ❌ 并写明原因，保留追溯。
