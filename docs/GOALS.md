> 目标编号规则：`M{n}` 为里程碑；`G-xx` 为北极星/成功指标。里程碑完成 = 交付物齐全 + 验收标准全绿 + PROGRESS 更新。

## 0. 北极星目标（North Star）

> **在 iPhone/iPad 上，用 LemonPlayer 打开光鸭云盘里的任意一部 MKV，3 秒内起播，ASS 字幕零配置还原，退出再进自动续播——全程不需要下载、不需要电脑。**

对应可量化指标：

| 编号 | 指标 | v1.0 目标 | 测量方式 |

| G-01 | P0 功能完成率 | 100% | REQUIREMENTS 清单勾选 |
| G-02 | P1 功能完成率 | ≥ 80% | 同上 |
| G-03 | 冷启动耗时（含登录恢复） | < 2.0s | Xcode Instruments / 打点日志 |

### M1 · 可编译骨架 + CI 出包

**目标**：打通"Windows 写码 → GitHub Actions 编译 → 产出 IPA"的闭环。这是整个项目的地基，必须最先做。

**交付物**
- Xcode 工程（`LemonPlayer.xcodeproj`，iOS 26 target，Swift 6，SwiftUI）
- SPM 本地模块骨架：`Core`、`Network`、`GuangyaAPI`、`Subtitle`、`Player`、`Media`、`Persistence`
- 占位 UI：登录页 / 浏览页 / 播放器页（可编译、可导航）
- `.github/workflows/build.yml`：模拟器构建 + 单测 + 未签名 IPA + artifact
- `docs/tech/CI_BUILD.md` 落地为实际配置

**验收**
- [x] push 后 Actions 全绿（build + test）—— run 41650264063，1m16s
- [x] artifact 里能下载到 `LemonPlayer-unsigned.ipa`（骨架版 22KB）
- [ ] 模拟器截图：三个页面可互相跳转（需 Mac/真机，延后到用户安装包验证）
- [x] 一键构建说明：CI 命令已写进 `docs/tech/CI_BUILD.md`

**风险**：Xcode 26 工程文件手写容易出错 → 已改用 XcodeGen 生成（`project.yml` 为唯一真相源）。

### M2 · 登录 + 网盘浏览

**目标**：用户能扫码登录并在 App 内浏览光鸭云盘目录。

**交付物**
- OAuth2 设备码登录（二维码展示、轮询、状态机）
- Keychain 持久化 + token 自动刷新（actor 化，防并发刷新）
- 目录列表（分页/下拉刷新/无限滚动）、面包屑、排序、搜索
- 错误态/空态/重试；请求限流与重试退避
- 单元测试：登录状态机、分页合并、错误映射

**验收**：J-01 前半段可用；token 过期自动续期；弱网下不崩溃。

---

### M3 · 播放内核 + 直链播放

**目标**：能播光鸭云盘上的 MKV，具备完整播放器交互。

**交付物**
- 播放内核集成（选型见 ADR-003）
- 签名直链获取 + 过期续签 + Range seek
- 播放器 UI：手势、进度条、倍速、音轨/内嵌字幕轨、锁定、全屏
- 后台音频 + 锁屏控制；播放错误自动恢复
- 单元测试：URL 续签策略、进度记录、内核桥接层状态机

**验收**：J-01 可播；4K HEVC MKV 硬解；seek 流畅；退后台音频不断。

---

### M4 · 外挂字幕（核心差异）

**目标**：字幕能力达到"字幕党"可接受水平。

**交付物**
- SRT/VTT/ASS 解析器（纯 Swift，含容错）+ 单测（覆盖率 ≥ 90%）
- 渲染：SRT/VTT 自绘 overlay（CoreText/SwiftUI），ASS 走内核 libass
- 同名自动匹配（规范化 + 语言后缀 + 多候选）、手动导入（文档选择器 + 网盘目录选）
- 编码检测（UTF-8/BOM/GBK/GB18030/BIG5/UTF-16）+ 手动覆盖
- 时间轴校准（0.1s 步进、实时预览、保存）、样式设置、双语字幕、按文件记忆
- 字幕预览页

**验收**：J-02 全绿；ASS 定位/字体/特效正确；GBK 不乱码。

---

### M5 · 媒体库 + 剧集

**目标**：从"文件浏览器"升级为"媒体库"。

**交付物**
- 文件名解析（标题/季集；中文季标题、SxxExx、罗马数字、合集/SP/剧场版）+ 单测
- **Bangumi 客户端**（公开接口：搜索/详情/剧集/图片；可识别 UA + ≥1 req/s 限流）
- 刮削编排：解析 → 搜索 → 匹配 → 人工纠正 → 落库 → 缓存
- 首页海报墙（继续观看/最近添加/分类）、详情页、剧集列表、自动连播、下一集预加载
- 播放历史、本地元数据缓存（离线可见）
- （P1）Bangumi OAuth 登录与收藏/单集进度同步

**验收**：首页断网仍可展示已缓存海报；剧集自动连播不中断。

### M6 · 离线缓存

**目标**：无网也能看，且字幕/续播能力不退化。

**交付物**

- 任务管理 UI（暂停/恢复/取消/优先级/批量）
- 缓存管理（容量统计、单删/全删、空间不足自动清理）
- 离线播放路径（本地文件 + 字幕 + 续播 + 倍速）

**验收**：J-03 全绿；杀进程后下载可恢复。

## 3. 执行节奏与协作机制

### 3.1 每轮迭代固定动作
1. **开始**：从 `docs/TASKS.md` 认领任务卡（状态 → Doing），在 `docs/PROGRESS.md` 写"本轮目标"。
2. **过程**：每完成一张卡 → 更新看板 + 进度日志（一行：日期、卡号、结果、CI 链接）。
3. **结束**：提交（Conventional Commits）、更新 PROGRESS 的"当前状态/下一步/阻塞"。

### 3.2 角色分工（Agent Teams）
| 角色 | 职责 | 写入范围 |
|---|---|---|
| Lead | 需求/目标/看板/进度、架构决策、集成与最终验收 | `docs/**`、`.github/**`、根配置 |
| 模块 Agent | 单模块实现（如 Subtitle、Player） | 对应 `Packages/<Module>/**` |
| 验证 Agent | 编译错误分析、单测补齐、回归清单 | 测试代码、`docs/qa/**` |

> 并行写同一文件会冲突：模块之间以 SPM package 为边界拆分写入范围；跨模块改动由 Lead 统一改。

### 3.3 里程碑验收会议（自检清单）
- [ ] 交付物齐全，文档已更新
- [ ] CI 绿，单测覆盖达标
- [ ] 关键旅程手工验证通过（有截图/录屏或日志）
- [ ] 遗留问题进入 `TASKS.md` Backlog，不静默丢失
- [ ] 需要上会讨论的决策 → 新增 ADR 草稿

### 3.4 变更控制
- 新增 P0 需求 → 必须置换出一个 P1，或调整 M7 范围，Lead 裁决并记录。
- 技术方案变更 → 先写 ADR，再动代码。
