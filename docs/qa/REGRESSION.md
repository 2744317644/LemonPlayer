## 三、已知限制（v2.0.0）

- 账号密码登录受光鸭风控限制，推荐网页登录/扫码。
- 模拟器 UI 截图中的播放器仍是竖屏（模拟器不响应方向锁定），真机横屏逻辑以 J-03a 验收为准。
- 字幕偶发不显示时，先看诊断页 `subtitle` 分类日志（下载 HTTP 码/挂载错误）。
- MKV 的画中画/AirPlay 受 VLCKit 限制（ADR-020）。
